# 小桃子品牌设计方案

> 状态：提案已接受，S1 已落地。落地顺序见 §6。本文档是品牌的唯一规范来源；插件只能消费，不能另立。
> 可视化原型板：[brand-board.html](brand-board.html)（浏览器直接打开）。

## 0. 诊断：为什么是「原型感」

不是不够好看，是缺三套系统：

- **icon 没有体系**：渠道 logo 风格粗细不一，功能图标散绘在各文件里；
- **token 只染了颜色**：圆角、动效、质感没有规则；
- **品牌没有出场规则**：什么时候出现、以什么形态出现，没有定义。

产品感 = 一致性 × 记忆点。一致性靠系统，记忆点靠那颗桃子。

## 1. 品牌一句话

**小桃子 = 住在你电脑里的工作伙伴。**

性格三词：**温暖、圆润、可靠**。每个视觉/文案决策都拿这三个词过筛：冷的不做、尖的不做、炫技的不做。

品牌标：`src/client/logo.ts` 内嵌的 APP_ICON（暖橙渐变 squircle + 有脸的桃子 + 绿叶）。`docs/ip.jpg` 与 `docs/welcome.png` 是插画资产，不是图标规范来源。

## 2. 视觉三要素

全部从 APP_ICON 像素级取样推导。

### 2.1 色

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 桃橙主色 | `#fc9052` → `#ed8644` | 品牌展示面（IP 底、欢迎卡、空状态托盘） |
| 奶桃 | `#fcab7f` | 高光、浅底强调、气泡 |
| 叶绿 | `#98a92d` | 唯一装饰点缀色（叶子、成功时刻装饰），**永不承担语义** |
| 深棕 | `#5b2413` | 品牌面内的重色（IP 上的文字/描边） |
| 交互填充 | `#b5522a`（light）/ `#f0a36f`（dark，配深字） | 按钮、选中态。必须过 WCAG AA（`#b5522a` 实测 4.98:1）；展示色不能直接当按钮色 |

实现：保留 `src/client/peach.ts` 的 `theme.overrideTokens` 管道和 light/dark 配对，**按上表重校色阶**。现有 `#a84c2c` 偏「熟桃红」，与图标的奶桃橙有温差。

### 2.2 形

- 圆角四档，收进 `--xtz-radius-*` 广播：**8（小件）/ 12（卡片）/ 16（面板）/ 999（胶囊、头像）**。
- 线条一律圆头（`stroke-linecap: round`），无直角末端。

### 2.3 质感

扁平 + 极轻暖渐变（≤5% 明度差）。禁止：投影堆叠、玻璃拟态、描边卡片叠描边卡片。

### 2.4 动效

- 时长两档：`--xtz-dur-fast: 120ms`（hover/press）、`--xtz-dur-base: 200ms`（进出场）；
- 缓动一条：`--xtz-ease-out: cubic-bezier(.2,.8,.2,1)`；
- 只动 `transform` / `opacity`；成功 = 轻微 scale 弹（1 → 1.04 → 1）；失败 = 水平 2px 抖一次；
- 全程尊重 `prefers-reduced-motion`。

## 3. Icon 体系

### 3.1 功能图标

规格：**24 viewBox、1.5px 圆头描边、`currentColor`、无填充**。

机制：插件不能跨包 import，所以 xtz-ui 不广播 SVG，只拥有规格（本节即规格）；每个插件只放自己用到的图标，按规格画。宁少勿多，缺了再画，不预设大全套。第一批约 24 个：连接、断开、刷新、二维码、文件夹、文档、机器人、消息、终端、git、发送、停止、设置、搜索、下载、上传、关闭、返回、更多、勾选、警告、信息、外部链接、加号。

### 3.2 渠道 logo

渠道色是渠道的品牌，不许改（微信绿、飞书蓝……）。统一靠**容器**：

- squircle 容器，固定尺寸档（22 / 32 / 38），圆角走 `--xtz-radius-*`；
- logo 图形占容器 60%，居中；
- 白底渠道（飞书、企业微信）加 1px `border-l2` 描边，彩色底渠道不加；
- 渠道只出「底色 + glyph」，不允许再调容器。

## 4. 品牌出场规则（白名单制）

| 形态 | 场合 |
| --- | --- |
| **露脸**（完整 IP） | 欢迎卡/首启、空状态、绑定成功、版本关于 |
| **露色不露脸** | 主按钮、选中态、hub 头部、关注气泡 |
| **完全中性**（DSH 原生色，品牌退净） | 删除确认、权限审批、错误详情 |

第三条与第一条同等重要：有脸的角色出现在破坏性平面上会稀释信任。信任时刻保持无品牌。

## 5. 文案语调（伙伴腔三条）

1. 说人话，给下一步：「没连上，二维码过期了，再扫一次」，而非「企业微信机器人没有绑定完成」；
2. 错误码、参考号收进次要行，不进主句；
3. 不用感叹号邀功，不用「请稍候」敷衍——要么说在做什么，要么别说。

## 6. 落地路线

每步独立可验证，按序进行。

- **S1 地基（xtz-ui）**：按 §2.1 重校 `peach.ts` 色阶；新增 `--xtz-radius-*` / §2.4 动效 token / 品牌 ink light-dark 配对的广播；本文档定稿。
- **S2 样板（xtz-ui 自己）**：欢迎卡 / 首启 overlay 用真 IP + 新 token 重做，成为所有插件的参照实现。
- **S3 消费（dsh-im、sidebar 等）**：渠道 logo 容器统一（§3.2）、空状态换品牌时刻、hub 头部、扫码绑定微时刻。一律消费 §2 的 token，不允许插件自造品牌色。
